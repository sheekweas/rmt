\section*{Data Availability}
The data analysed in this study are the Deceptive Opinion Spam corpus v1.4 of Ott et al.\ \cite{ref22,ott2013}, which is publicly available under a Creative Commons Attribution-NonCommercial-ShareAlike 3.0 licence from the authors' page (\url{https://myleott.com/op-spam.html}). Because the author-hosted archive could not be downloaded, the copy used here was obtained on 9 November 2026 from the public mirror at \url{https://git.science.uu.nl/r.vandenbrink/datamining-a2/-/tree/master/op_spam_v1.4}; the downloaded archive has SHA-256 \nolinkurl{f6b9ce960ffd67086e8713d82f2cfb289ef3c14d3366ea020c628a9302a1c287}. The raw review texts are not redistributed with this article. Derived data that are sufficient to verify every reported result, namely the SHA-256 hash of each of the 1,600 review files (\texttt{data\_manifest.csv}), the partition and fold assignments (\texttt{split\_assignments.csv}), all model probabilities and the computed summaries, are included in the \texttt{results} folder of the code archive described below. The YelpChi collection named in the original protocol was not obtained or analysed; it is available from its maintainer on request \cite{ref21}. No new data were collected from human participants.

\section*{Code Availability}
All code used for data auditing, partitioning, model training, statistical analysis and figure generation is provided with this article as a supplementary archive (\texttt{Kurmash\_BDA-2402\_code.zip}, release v1.0) under the MIT licence, and is publicly available in the GitHub repository \url{https://github.com/sheekweas/rmt} (folder \texttt{code}). The code is written in Python 3.14.3 and uses PyTorch 2.11.0 with CUDA 12.8, Hugging Face Transformers 5.22.2, scikit-learn 1.9.1, NumPy 2.5.4, pandas 3.1.1, SciPy 1.18.1 and Matplotlib 3.11.2. The exact environment is specified in \texttt{requirements.txt} (direct dependencies) and \texttt{requirements-lock.txt} (full \texttt{pip freeze}); the RoBERTa weights are the public \texttt{FacebookAI/roberta-base} model at revision \nolinkurl{e2da8e2f811d1448a5b465c236feacd80ffbac7b}. Running \nolinkurl{scripts/download_data.py}, \nolinkurl{scripts/run_experiments.py} and \nolinkurl{scripts/analyze.py} in sequence reproduces all tables and figures; the full experiment took 12.6 minutes on an NVIDIA RTX 4060 Laptop GPU. No proprietary software was used.
